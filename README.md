# Neon Arena

ATHLETIX — VISUAL DESIGN & UI DIRECTION

Use a dark, premium, futuristic sports-tech aesthetic throughout the entire ATHLETIX website.

The primary visual identity MUST be:

DARK THEME + NEON GREEN

Do not use a light theme as the primary experience.

1. CORE VISUAL IDENTITY

ATHLETIX should visually feel like a combination of:

High-performance sports technology

Professional athlete analytics

Modern startup platform

Premium networking product

Futuristic talent-discovery system

Think:

Nike performance technology + modern SaaS dashboard + LinkedIn professional identity + sports analytics.

The interface should feel:

Fast

Powerful

Premium

Competitive

Technical

Trustworthy

Youthful

Avoid making it feel:

Cartoonish

Gaming-focused

Overly flashy

Like a generic fitness app

Like a basic CRUD college project

2. COLOR SYSTEM

Use a very dark background as the foundation.

Primary Background

Near-black / charcoal:

#050505

or similar.

Secondary Background

Dark charcoal:

#0B0F0C

Cards

Use slightly lighter dark surfaces:

#101610

Cards should be clearly distinguishable from the background without looking bright.

Primary Accent

Use NEON GREEN as the main brand color.

Suggested:

#39FF14

You may use a slightly more sophisticated neon-green variation where appropriate.

Secondary Green

Use darker green tones for:

Hover states

Borders

Background gradients

Selected states

Text

Primary:

White / near-white

Secondary:

Muted gray

Disabled:

Dark gray

3. NEON GREEN USAGE

Neon green should be used strategically.

Use it for:

Primary CTA buttons

Active navigation

Verification badges

Important statistics

Progress indicators

Selected filters

Performance improvements

Success states

Important icons

Graph highlights

Hover effects

Small glowing accents

Do NOT make every element neon green.

The neon green should stand out because the rest of the UI is dark.

4. GLOW EFFECT

Use subtle neon-green glow effects.

Examples:

Buttons can have a subtle green glow on hover.

Cards can have a very faint green border glow when selected.

Verification badges can have a subtle green glow.

Performance graphs can use neon-green strokes.

Do NOT use excessive glow.

The website should remain professional rather than looking like a gaming website.

5. TYPOGRAPHY

Use a modern sans-serif font.

Prefer:

Inter

or another clean modern UI font.

Typography should be:

Bold

Clean

High contrast

Spacious

Large headings should be powerful and minimal.

Example:

Talent shouldn't go undiscovered.

Use large typography on the landing page.

6. LANDING PAGE VISUAL STYLE

The landing page should immediately communicate:

ATHLETIX = professional sports + technology + opportunity

Use a dark hero section with subtle abstract sports-tech visuals.

Possible visual elements:

Abstract running track lines

Athletic silhouette

Performance graph

Floating athlete profile cards

Verification badges

Achievement cards

Small neon-green data points

Network connection lines

Keep the composition clean.

Do not overcrowd the hero section.

7. ATHLETIX LOGO

Create a simple wordmark:

ATHLETIX

Use:

Bold typography

White logo text

Small neon-green accent

The logo should be text-based if no actual logo asset exists.

Possible treatment:

ATHLE in white

TIX in neon green

Keep it simple.

8. BUTTON DESIGN

Primary buttons:

Dark background page + neon-green button.

Example:

Get Started →

Button characteristics:

Rounded corners

Neon-green background

Black text

Medium/large size

Slight glow on hover

Secondary buttons:

Transparent background

Thin dark-gray/green border

White text

Neon-green hover state

Destructive buttons should NOT use neon green.

9. CARDS

Use dark cards with:

Rounded corners

Subtle borders

Very subtle shadows

Large spacing

Clean typography

Cards should feel like premium glass/dark surfaces.

On hover:

Slight upward movement

Border becomes neon green

Very subtle green glow

10. PROFILE DESIGN LANGUAGE

Athlete profiles should feel like professional sports resumes rather than social media profiles.

Prioritize:

Performance → Achievements → Verification → Progress → Opportunities

Do not emphasize:

Likes

Followers

Comments

Social-media style engagement

ATHLETIX is a professional network, not a social media app.

11. VERIFICATION BADGES

Make verification a major visual component.

Use a small neon-green badge:

✓ VERIFIED

or

✓ ATHLETIX VERIFIED

It should immediately communicate credibility.

For unverified documents use:

PENDING

with a muted amber/orange treatment.

For documents requiring review:

REVIEW REQUIRED

12. ATHLETE PROFILE VISUAL HIERARCHY

The athlete's name should be prominent.

Example:

Aarav Sharma

400m Athletics

Pune, Maharashtra

✓ VERIFIED ATHLETE

Then immediately show:

PERFORMANCE

Personal Best

Other metrics:

State Level

Performance Improvement

Use large numbers.

This should visually resemble a professional athlete analytics dashboard.

13. PERFORMANCE GRAPH

Use a dark chart.

Neon-green line.

Show improvement over time.

Example:

2024 → 51.4 sec

2025 → 50.1 sec

2026 → 48.92 sec

Highlight the latest performance with a neon-green point.

Title:

Performance Progress

Subtitle:

Improving trajectory

DISCOVERY

Discover Athletes

Then:

Filters

Sport

Location

Competition Level

Achievement

Performance

Then:

Recommended Athletes

CTA:

All three experiences should feel like the same platform but have different priorities.

ATHLETE

Primary color emphasis:

Performance

Achievements

Verification

Goals

Primary emphasis:

Discovery

Primary emphasis:

Talent

Do not create three completely different designs.

Maintain one ATHLETIX brand system.

20. NAVIGATION

Use a modern dark navigation bar.

Desktop:

ATHLETIX logo on left.

Navigation in the center/left.

User profile and notifications on right.

For dashboards, a left sidebar can be used.

Sidebar:

Discover

Profile

Shortlisted

Connections

Opportunities

Notifications

Settings

The currently selected item should have a neon-green indicator.

21. MICRO-INTERACTIONS

Use subtle interactions everywhere.

Examples:

Button hover

Neon glow + slight scale.

Cards

Slight lift on hover.

Verification

Badge gently highlights.

Shortlist

Button changes from:

Shortlist

to:

✓ Shortlisted

Connect

Button changes to:

Request Sent

Search

Results animate smoothly into view.

Filters

Selected filters become neon green.

22. PAGE TRANSITIONS

Use subtle transitions between the eight main frames.

Do NOT make transitions slow.

Everything should feel fast and responsive.

Use approximately:

150–250ms transitions.

23. EMPTY STATES

Keep empty states on-brand.

Dark background.

Minimal icon.

Neon-green accent.

Example:

No athletes found

Try adjusting your filters.

Button:

Clear Filters

24. MODALS

All modals should use:

Dark background

Rounded corners

Subtle border

Neon-green primary CTA

Dimmed background

Example:

Connect with Aarav

Message:

Introduce yourself...

Send Request

25. MOBILE DESIGN

On mobile:

Convert desktop sidebar to bottom navigation or hamburger navigation.

Stack profile statistics.

Make search and filters horizontally scrollable.

Keep CTA buttons easily accessible.

Profile cards should become single-column.

Preserve the dark + neon green identity.

26. LANDING PAGE SECTIONS

Use the following landing page structure:

Navigation

Hero

Problem

ATHLETIX Solution

Three Roles

How ATHLETIX Works

Sports Ecosystem

AI / Verification

Discovery Preview

Final CTA

Footer

Use the project's central message:

Talent is everywhere. Opportunity isn't.

And the final brand line:

DISCOVER. VERIFY. CONNECT. RISE.

27. AI / TECHNOLOGY VISUAL

Create a section showing that ATHLETIX is technology-enabled.

Show three connected stages:

DOCUMENT

↓

AI VERIFICATION

↓

TRUSTED PROFILE

Then:

PERFORMANCE DATA

↓

RECOMMENDATION ENGINE

↓

TALENT DISCOVERY

This should be visually represented using dark cards and neon-green connection lines.

Keep the AI functionality simulated for the MVP.

28. OVERALL DESIGN RULE

When making a design decision that isn't explicitly specified above, prioritize:

Dark → Minimal → Premium → Athletic → Data-driven → Neon Green Accent

Do not introduce random colors.

Do not use excessive gradients.

Do not use excessive rounded elements.

Do not make everything glow.

The final website should look like a real venture-backed sports-tech startup product.

29. MOST IMPORTANT REQUIREMENT

The first impression should be:

"This looks like a serious professional platform for athletes."

Not:

"This looks like a student sports website."

The interface must feel polished enough to present directly to hackathon judges.

Maintain consistency across all eight frames:

Frame 1 — Landing

Frame 2 — Role Selection

Frame 3 — Athlete Login

Frame 4 — Coach Login

Frame 5 — Sponsor Login

Frame 6 — Athlete Profile

Frame 7 — Coach Discovery/Profile

Frame 8 — Sponsor Discovery/Profile

Every screen should clearly belong to the same ATHLETIX design system.
